# TapNova
1. Décompressez le ZIP. 2. Créez un dépôt GitHub **public** et envoyez-y tous les fichiers (ils sont tous au même niveau). 3. Ouvrez `https://app.netlify.com/start/deploy?repository=LIEN_DE_VOTRE_DEPOT` et remplissez les variables.
Avant cela : exécutez `supabase.sql` dans Supabase (SQL Editor) et créez un compte Cloudinary pour obtenir les 3 valeurs demandées.
Aucun secret n'est dans ces fichiers. Admin : `/admin.html`, mot de passe = valeur de `ADMIN_KEY`. Si le lien d'un profil change, régénérez le QR Code imprimé.
